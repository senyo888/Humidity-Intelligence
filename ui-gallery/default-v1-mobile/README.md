# Default V1 Mobile

- Style: legacy-compatible mobile layout with comfort band and humidity constellation
- Optimised for: phones and users keeping a V1-style dashboard presentation
- Author: @senyo888
- Source template: `ui/cards/v1_mobile.yaml`
- Required custom cards: `card-mod`, `button-card`, `mod-card`, `apexcharts-card`

[![Default V1 Mobile preview](preview.png)](preview.png)

## Notes

This example preserves the V1-style mobile presentation while using the V2 integration's canonical generated entities and semantics. It is useful for users who prefer the comfort-band and humidity constellation style over the newer V2 control-surface layout.

The YAML is copied from the canonical generated card template and should be treated as an example artifact. In a real installation, prefer the card YAML exported by `humidity_intelligence.dump_cards` so placeholders match your generated entities.
