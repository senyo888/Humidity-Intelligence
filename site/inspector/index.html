01
Diagnostic contents remain in this browser tab.

Processing is browser-local and in-memory, with diagnostic-content upload, network APIs, analytics, logging, browser storage, persistence and retention excluded. Selecting another file or closing the tab clears the in-memory result. The static host receives normal page-request metadata; selected file contents remain in this tab.

02
Home Assistant and HI remain authoritative.

The Inspector presents allowlisted backend-reported support summaries alongside separately labelled local privacy-pattern category counts. Those local counts are an advisory preflight. Runtime decisions, source authentication, live-state verification, reason and lane selection, support action and control remain with Home Assistant, HI and maintainer review. Privacy and anonymity assessment remain with the user.
