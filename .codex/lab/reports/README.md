# HA Lab Reports

This folder holds local-only redacted evidence from approved HA Lab Runtime checks.

Report authority rule: individual reports are historical evidence by default. The
current live baseline is the baseline pointer named below; older reports must not be
treated as competing runtime truth, release authority, or implementation approval.

HA Lab is admitted as Operational Beta Validation Infrastructure. Reports may feed
beta-readiness, PR, Bella, Aetherwing, AetherCore, and maintainer review as advisory
evidence, but they are not release authority, runtime authority, stable Home Assistant
authority, or permission for autonomous mutation.
