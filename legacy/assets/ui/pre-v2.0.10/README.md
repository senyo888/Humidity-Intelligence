# Pre-v2.0.10 UI asset archive

This directory preserves screenshots and the historical quick demo that previously
lived in active README, site, and gallery asset paths. They predate the refreshed
`2.0.10-beta.7` cards and must not be presented as current package evidence.

The subdirectories preserve the former asset locations:

- `assets-readme/` — formerly under `assets/readme/`
- `assets-root/` — formerly at the root of `assets/`
- `assets-v2-ui-gallery/` — formerly under `assets/v2_ui_gallery/`

The deprecated V1 preview remains active at
`assets/readme/ui_v1_mobile.png` because it is still a compatibility-significant
historical example. Duplicate V1 copies were archived here.

For current public images, use `assets/ui/v2.0.10-beta.7/`.
